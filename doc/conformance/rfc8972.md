# RFC 8972 conformance

Revision frozen: RFC 8972, January 2021; source checked 22 July 2026.
[Source](https://www.rfc-editor.org/rfc/rfc8972.html).

The matrix includes verified errata [8199](https://www.rfc-editor.org/errata/eid8199)
(DSCP/ECN copy fields) and [8339](https://www.rfc-editor.org/errata/eid8339)
(Follow-Up TLV length validation). Session-admission rows require provisioned
mode. Clock sources are operator declarations; physical synchronization is unverified.

## Scope

Rows cover protocol requirements and selected format definitions; introductions,
keyword boilerplate, and registry administration add no runtime requirements.
The [rollup](README.md) explains scoring and verification limits.

Location replies use the specified unknown-MAC fallback. Keyed replies may add
an HMAC TLV when the request omitted it, as disclosed in RFC8972-4.8-1.
