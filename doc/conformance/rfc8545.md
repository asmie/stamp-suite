# RFC 8545 conformance

This matrix maps the normative clauses of RFC 8545 (well-known port
assignments for OWAMP and TWAMP) to stamp-suite. It is for reviewers checking
which port rules apply to a STAMP implementation.

Revision frozen: RFC 8545, March 2019.
Source: [RFC 8545](https://www.rfc-editor.org/rfc/rfc8545.html).

Summary: 8 clauses: 1 Compliant, 0 Partial, 0 Gap, 7 N-A, 0 Excluded.

## Scope

stamp-suite implements STAMP (RFC 8762), which has no OWAMP or TWAMP TCP
control exchange. The port-selection clause applies. The clauses about
OWAMP/TWAMP branding and control messages (Request-Session,
Request-TW-Session, Accept-Session) have no counterpart in STAMP and are N-A.
The informative ECMP, security and historical sections add no normative
clauses.

## Clauses

| ID | Clause | Level | Role | Status | Evidence |
|---|---|---|---|---|---|
| 8545-4-1 | "the implementation of both OWAMP-Control and OWAMP-Test is REQUIRED for Standards Track OWAMP as specified in [RFC4656]" | REQUIRED | N-A | N-A | stamp-suite does not implement OWAMP (RFC 4656). |
| 8545-4-2 | "the implementation of both TWAMP-Control and TWAMP-Test is REQUIRED for Standards Track TWAMP as specified in [RFC5357]" | REQUIRED | N-A | N-A | stamp-suite does not implement TWAMP (RFC 5357) or TWAMP-Control. STAMP runs test sessions without a TCP control exchange (RFC 8762 §1). |
| 8545-5-1 | "The use of this UDP port is OPTIONAL in Standards Track OWAMP and TWAMP" | OPTIONAL | Both | Compliant | `src/configuration.rs::Configuration::remote_port` and `src/configuration.rs::Configuration::local_port` default to 862 and are set with `--remote-port`, `--local-port` or the configuration file. Configuration tests cover the default and file and CLI overrides. |
| 8545-5.1-1 | "the Server at the Session-Reflector MAY suggest an alternate and available port for this session in the Port field" [Erratum 1587 correction to RFC 5357 §3.5] | MAY | N-A | N-A | TWAMP-Control Accept-Session semantics. STAMP has no control messages and no Port field. |
| 8545-5.1-2 | "...the Server uses the Accept field to convey other forms of session rejection or failure to the Control-Client and MUST NOT suggest an alternate port" [same corrected paragraph] | MUST NOT | N-A | N-A | TWAMP-Control Accept-Session semantics; see 8545-5.1-1. |
| 8545-5.1-3 | "...in this case, the Port field MUST be set to zero" [same corrected paragraph] | MUST | N-A | N-A | TWAMP-Control message field; see 8545-5.1-1. |
| 8545-5.1-4 | "A Control-Client that supports the use of the allocated TWAMP-Test Receiver Port (Section 7) MAY request to use that port number in the Request-TW-Session command" | MAY | N-A | N-A | TWAMP-Control Request-TW-Session command. The sender sets the destination port directly with `--remote-port` (`src/configuration.rs::Configuration::remote_port`). |
| 8545-5.2-1 | "an OWAMP-Control client that supports the use of the allocated OWAMP-Test Receiver Port (Section 7) MAY request to use that port number in the Request-Session command" | MAY | N-A | N-A | OWAMP-Control Request-Session command. stamp-suite implements neither OWAMP nor OWAMP-Control and defaults to port 862, not the OWAMP-Test port 861. |
