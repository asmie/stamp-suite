# RFC 8545 conformance

Revision frozen: RFC 8545, March 2019; source checked 22 July 2026.
[Source](https://www.rfc-editor.org/rfc/rfc8545.html).

STAMP has no OWAMP/TWAMP TCP control exchange. The port-selection clause applies;
control-message and protocol-branding clauses are N-A.
