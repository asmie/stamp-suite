# draft-ietf-ippm-stamp-ext-hdr conformance — stamp-suite

Revision frozen: draft-ietf-ippm-stamp-ext-hdr-**13**, 9 September 2026
Source: https://www.ietf.org/archive/id/draft-ietf-ippm-stamp-ext-hdr-13.txt

This is an **Internet-Draft, not a published RFC**. This matrix supersedes the
revision-11 matrix in git history. The audit uses the complete revision-13 text
retained with the September review, including the eight-octet Type 246 change
missed by the initial delta summary. It does not relabel the old clause scores.

Summary: 60 clauses — 54 Compliant / 0 Partial / 0 Gap / 6 N-A / 0 Excluded

Type 246 uses **Requested(8) + Reflected(Length−8)**. Type 247 remains
**Requested(4) + Reflected(Length−4)**. A zero selector remains zero in the
reply; an eight-byte extension-header request therefore has no Reflected tail.
The wire format is incompatible with revision-11 Type 246 interpretation.
Peers must agree on this draft revision and experimental Type 246/247 and
control sub-TLV 240 codepoints; no IANA allocation is claimed.

Compliance below is within the supported profile: kernel UDP with checksums,
Linux origination of attached headers and route-aware MTU enforcement, and
raw capture for successful header reflection. Nix returns the draft-specified
C flag when headers cannot be accessed. Both backends use the specified C-flag
fallback for unsupported reverse-header attachment. Unknown MTU budgets fail
closed. IPv6 zero-checksum and IOAM processing are not implemented.
All deployments require provisioned endpoints, sufficient offered-load capacity
and the draft's single-administrative-domain assumptions. Physical capture and
cross-platform validation limits are recorded with the test evidence.

## Coverage boundaries

The table inventories uppercase normative clauses, with §7.1's SHOULD expanded
into its four required state outcomes. Figures 6/7 are reflected in the field
width/length rows. Keyword boilerplate, topology examples, IOAM descriptions,
implementation-status editorial text and IANA registration procedures impose
no additional local runtime feature. Conditional zero-checksum subconditions
(port scoping, controlled domain, payload integrity, middleboxes and corruption)
remain inapplicable because that mode is absent. Incorporated RFC requirements
retain their own matrices; this is not a new audit of every cited document.
