## Scope and verification

SR-MPLS forwarding is unsupported and returns U. Control Code 1 uses normal
routing; the implementation does not pin the outgoing interface on a multihomed
host. Combined Return Address/Segment List selection has the limits in 9503-4-3.

The [independent UDP fixture](../testing-interop.md) checks Type 9 acceptance,
Type 10 U fallback, CoS, directory keys, bursts, and both HMACs. It does not prove
multihomed source override or SRH forwarding.

`scenario_3_srv6_return_path` separately requires successful Linux/nix SRv6
transit. Captures before and after a router check headers, segment progression,
Hop Limit, CoS, flags, HMACs, and interleaved ordinary replies. Pnet retains U
fallback. See [namespace tests](../testing-netns.md).
